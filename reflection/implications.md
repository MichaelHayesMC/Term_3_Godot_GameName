## 2️⃣ Aesthetics

__Does it Look Good?__  
__How does your choice in design influence human emotion?__

### Design Elements - Individual Features

__Line__  
I have used a multitude of division lines such as frame widgets to separate the two differently functioning widgets. These rigid lines create a sense of organisation, mild complexity and minimalism. The lines cause the viewer's eyes to become limited in the borders/confines that the lines create, ensuring that the user knows what is relative to each other such as the input and the outputs.
Lines have been used to separate the different elements (buttons and treeview table)

__Shape__  
I have consistently used rounded GUI buttons, comboboxes, treeview widgets etc. This creates a sense of modernisation where the rounded buttons show a sense of complexity and futuristic GUI that is repeated alongside other GUI interfaces of modern OS systems. My GUI replicates some similarities of the Windows 11 system that is most recent to 2024. This demonstrates that my GUI interface is relatively new and complex to this era rather than having ragged edges that would look more to a limited primitive world of cubic shapes rather than rounded.
Rounded GUI Buttons

__Colour__  
Firstly, I have integrated the use of the colour black throughout my program. This sleek black design represents the modern theme that I was going for, for my minimalistic and modern outlook. Black represents elegance and formality. My program is mainly used for formal scenarios that the user would want to organise their tasks for a long period of time. I had also chosen it due to the ability to make it less straining on the eyes of the user when they use it at late hours. It makes it more versatile for different work times that the user would like to update the task manager.

Secondly, I have integrated the use of the colour blue throughout my program. Blue represents stability, formality, calmness and success. I have used it because it invokes a sense of productivity for the user while also being less straining for the eyes. It compliments the black accent nicely and is easy to see against it since it is a vibrant colour. Ultimately it makes the program look professional for professional work and complex daily life management.
Black - Helps with the eyes
Blue - Compliments the black nicely

__Texture__  
I have used a sleek smooth plastic imitating design. The programme uses a soft black background and blue buttons to create a smooth, modern texture, which makes the interface feel calm and user-friendly. The flat texture creates a clean and minimal sense to the user giving it the idea that it is meant for professional use.
Smooth Modern Texture

### Design Principles - How Design Elements Work Together

__Alignment__  
I have incorporated alignment in my programme through the use of separating the interactive widgets and the output display of the tasks in the task manager. This gives a more professional feel to the programme as it allows the user to easily navigate throughout the task manager interface to know where they can modify the widget properties or to make one entirely and furthermore manage it later on.
Widget Alignment using frames

__Contrast__  
I have incorporated contrast between my widgets to make it easier to know what I want the user to look at first. The blue contrast from the black background indicates that these are buttons and can be pushed in comparison to a black stationary background. The blue implies that it has function, purpose and meaning to show it really pops to the user to know that it can be pushed to do a certain action like modifying or creating a task. Furthermore it creates emphasis on the functionality of the programme and what can be interacted with.
Colour Contrast between Blue and Black.

__Rhythm / Repetition__  
I have incorporated repetition through repeating the black and blue theme, the use of lines to separate widgets and repeatedly used rounded widgets. This creates a professional and minimalistic look. The use of repetition creates a sense of rhythm within my programme, making it look clean and organised for that formal professionalism every time it is opened by the user for easy navigation.
Repetition of the shape of GUI and colour pallete

## 3️⃣ End User Considerations

__What Specific Needs does your end user have?__

My program fulfills the initial purpose that I had stated at the beginning of my intent for the project. My aim for this project was to make a task manager that would display the intended tasks of the user and allow them to analyse what things they would need to do.

I have implemented the use of entry widgets, button widgets, frames, treeview tables and comboboxes to make my program.

__Entry Widget__ - Prompt the user for a task label/description

__Buttons__  
Add Task - _Creates a task based on the given information when all properties have an input_  
Remove Task - _Removes the selected task by the user in treeview table_  
Select Modify - _Fills the properties widgets with the information based on the treeview table task_  
Modify Selected - _Confirms the changes made if any are made by the user into the task treeview table_  

__Comboboxes__  
Date Due - _Prompts the user for day/month/year of the due date by user_  
Priority - _The urgency of the task with the following (Low, Medium, High)_  
Status - _How the user is dealing with the task (To Do, Doing, Done)_  

My program officially provides the user with all the requirements they would need to create and organise tasks that they need to do when they need to do it.
